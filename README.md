# 🌱 EcoEnergia

Plataforma web educativa desenvolvida como projeto acadêmico na disciplina UPX do curso de Engenharia da Computação da FACENS.

## 📚 Sobre o projeto

O EcoEnergia tem como objetivo ajudar pais e professores a ensinarem crianças sobre economia de água e energia de forma divertida e interativa.

A plataforma busca unir tecnologia e educação para incentivar hábitos mais sustentáveis desde cedo.

## 🚀 Funcionalidades

* Cadastro e login de usuários
* Teste de nível de conhecimento
* Quiz interativo
* Sistema de pontuação e níveis
* Conteúdos sobre economia de água e energia
* Interface voltada para o público infantil

## 💻 Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* Git
* GitHub

## 🎓 Contexto acadêmico

Projeto desenvolvido durante a disciplina UPX da FACENS, que tem como proposta aplicar os conhecimentos adquiridos durante a graduação na criação de projetos práticos e multidisciplinares.
